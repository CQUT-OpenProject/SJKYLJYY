## 结果中的边界情况

- 实验二直接修改被引用的类别主码、删除仍有销售记录的商品，实际返回外键错误 1451。保留错误记录，并验证先处理子表引用的事务方案；未关闭外键检查。
- 年龄按执行年份减出生年份计算。本次年份为 2026，22～24 岁查询返回空集；低库存、2019 年购买数量超过 5 等条件也可能返回空集。补充样本验证相应条件后回滚。
- 实验四未给 `V_MIS` 增加题目没有要求的 `WITH CHECK OPTION`。IT 学生可经视图插入基本表，但在 MIS 视图中不可见；删除该不可见记录影响 0 行。
- 原始样本没有“力神咖啡”，相应更新影响 0 行。另用事务内临时商品验证连接视图更新，成功后回滚。聚合视图更新实测失败，带 `CHECK OPTION` 的对照视图也实际拒绝不满足条件的插入。

## 运行 SQL

在本目录执行：

```sh
# 仅在目标数据库尚不存在时运行；脚本拒绝覆盖现有数据库。
python3 scripts/run_experiment.py
python3 scripts/run_remaining.py
```

运行脚本默认通过本地 socket 使用 root，可通过 `MYSQL_BIN` 和 `MYSQL_USER` 指定客户端及用户。后续实验的预期年龄结果记录的是 2026 年的执行环境；跨年份复跑时需核对年龄预期。

实验二至四的 `sql/setup.sql` 用于创建结构；实验二在第 1 题导入数据，实验三、四在初始化时导入。实验二 SQL 包含需要观察的预期错误，直接批量运行会在错误处停止，可使用运行脚本逐步记录与验证。数据库导出表示完成实验后的状态，导入会修改其中指定的数据库，应在独立环境中使用。
